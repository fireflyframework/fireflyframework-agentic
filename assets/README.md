# Firefly Agentic brand assets

The visual identity used across the README. **Firefly Agentic is the agentic
member of the [Firefly Framework](https://github.com/fireflyframework) family** —
the same firefly-in-the-dark language as the Java / .NET / PyFly / Rust siblings,
recolored to a violet "intelligence" palette. The amber firefly glow-dot is the
shared family firefly; everything else carries the member's violet identity.

## Design system

- **Typeface:** the `firefly` wordmark is the family brand logo embedded as vector
  paths (no web fonts); diagram text uses the system sans / `ui-monospace` stacks.
- **Violet palette:** primary `#8b5cf6` · `#7c3aed` / `#6d28d9` · mid `#5b21b6` ·
  deep `#4c1d95` · ink `#1e1633` · body `#322b45` · muted `#8b82a3` · panel
  `#f5f2fe` · stroke `#e4def5` · wordmark grad `#d6c6ff → #a78bfa → #7c3aed`.
- **Shared firefly:** glow-dot `#FFF9C1 → #F68000`, warm amber motes `#f6a821`
  (the family firefly) — a deliberate violet ↔ amber contrast.
- **Banner sky:** `#0b0a14 → #120d1c → #140f1e` with a violet radial ambient.
- **Motifs:** firefly motes, a violet title rule, deep-violet numbered badges,
  monospace module lists, brand icons ([Simple Icons](https://simpleicons.org/)),
  and a spark for the agentic member.
- **GitHub-safe:** every SVG is self-contained — no `<script>`, no external
  references, no web fonts; ASCII-only connectors (`->`) and drawn icons (no
  fragile Unicode glyphs); opaque light cards that read in light and dark mode.

## Regenerating

Everything is generated by one self-contained, offline script. It needs
**fontTools** (text metrics → guaranteed fit) and, to render/verify,
**cairosvg** (already shipped in the `[binary]` extra):

```bash
uv pip install fonttools                    # build-time only; not a runtime dependency
.venv/bin/python assets/tools/build_brand_assets.py
```

It embeds the `firefly` wordmark from [`tools/wordmark.py`](tools/wordmark.py)
(extracted from the brand logo), draws the banner and eight diagrams from the
shared kit (measured text → guaranteed fit, plus an automatic overlap check that
prints `WARNINGS: none`), and writes all nine SVGs. The brand icons are vendored
in [`tools/icons.py`](tools/icons.py), so the build is fully network-free.

### Previewing / verifying

```bash
.venv/bin/python -c "import cairosvg; cairosvg.svg2png(url='assets/banner.svg', write_to='/tmp/banner.png', output_width=1280)"
```

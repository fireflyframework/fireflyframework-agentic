Why a metaframework

Keep the engine.
Gain the architecture.

Pydantic AI gives you type-safe, model-agnostic agents. A production system needs more: orchestration, validation-and-retry, memory across turns, traces and budgets, experiments. Firefly Agentic supplies every one of those as a dedicated, swappable layer — so your business logic never couples to infrastructure.

  • Build with FireflyAgent, ToolKit, MemoryManager and ModelOptions.
  • Lifecycle hooks, registries, delegation, memory, reasoning, validation and pipelines wrap them — all optional, all composable.
  • Keep model selection in configuration; Firefly validates options against each provider. Native SDK integrations remain available.

Architecture

One application API, composable capabilities

Firefly agents, tools, memory and model options form the application boundary. Add reasoning, validation, experiments and orchestration as needed.

Extend components through structural protocols or abstract base classes. Runtime-checkable protocols support instance checks; register or attach your implementation explicitly.

Models and APIs

Keep your agent. Choose your API.

Existing openai: and azure: selectors retain Chat Completions. Choose openai-responses: or azure-responses: explicitly for Responses. Firefly validates typed options against the selected model.

Five minutes in

Familiar Python, all the way down

Async-first, typed, and decorator-friendly. Set your provider key and FIREFLY_AGENTIC_DEFAULT_MODEL, then run these cells in a notebook. Select openai-responses:gpt-6-luna for reasoning with tools.

assistant.py
from fireflyframework_agentic.agents import FireflyAgent
from fireflyframework_agentic.models import ModelOptions
from fireflyframework_agentic.tools.builtins import CalculatorTool

agent = FireflyAgent(
    name="assistant", tools=[CalculatorTool()],
    model_options=ModelOptions(max_tokens=4096),
)
result = await agent.run("Calculate 15 percent of 240.")
print(result.output)
from fireflyframework_agentic.agents import FireflyAgent
from fireflyframework_agentic.memory import MemoryManager

memory = MemoryManager(max_conversation_tokens=32_000)
agent = FireflyAgent(name="bot", memory=memory)
cid = memory.new_conversation()
await agent.run("My name is Alice.", conversation_id=cid)
result = await agent.run("What's my name?", conversation_id=cid)
print(result.output)
from fireflyframework_agentic.agents import FireflyAgent
from fireflyframework_agentic.reasoning import ReActPattern

agent = FireflyAgent(name="reasoner")
react = ReActPattern(max_steps=5)
result = await react.execute(agent, "Explain bounded retries and backoff.")
print(result.output)
from fireflyframework_agentic.agents import FireflyAgent
from fireflyframework_agentic.pipeline import PipelineBuilder, AgentStep

summarizer = FireflyAgent(name="summarizer", instructions="Summarize in one sentence.")
editor = FireflyAgent(name="editor", instructions="Rewrite the summary clearly.")
pipeline = (
    PipelineBuilder("summarize-and-edit")
    .add_node("summarize", AgentStep(summarizer))
    .add_node("edit", AgentStep(editor))
    .chain("summarize", "edit").build()
)
result = await pipeline.run(inputs="Retries stop after three attempts.")
print(result.final_output)
